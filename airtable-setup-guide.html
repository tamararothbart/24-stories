BookProductionStatus — formula to paste

In Airtable, add a Formula field named BookProductionStatus and paste this exactly:

IF({BookSentToPrintDate}, "At Printer", IF({BookCompiledDate}, "Ready for Print", IF({BookFormCompleted}, "In Design", "")))

Airtable view to build: "Books in Production"

In the Subscribers table
  1. Click + Add a view → Grid view → name it Books in Production
  2. Add filter: BookFormCompleted — is not empty
  3. Sort by: BookFormCompleted — ascending (longest waiting first)
  4. Hide all fields except: StorytellerFirstName, BookProductionStatus, BookFormCompleted, BookCompiledDate, BookSentToPrintDate

SubscriberRecordID — formula to paste

In Airtable, add a Formula field named SubscriberRecordID and paste this exactly:

ARRAYJOIN({SubscriberID}, "")

This outputs the linked subscriber's Airtable record ID as plain text. library.html uses it to filter stories by subscriber. Without it, the library cannot load.
