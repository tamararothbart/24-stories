Compile a subscriber's book

Use this page after you have generated and reviewed the chapter order. Compiling assembles all stories, images, and book details into a print-ready document.

Find this in Airtable: open the subscriber record — the ID is in the URL bar (starts with "rec").

Preview in browser ↗

What each action does

  1. Preview in browser — opens the complete book in a new tab so you can review all chapters, images, and order before sending to print. The printer specification panel appears at the top of the preview and is automatically hidden when you export to PDF.
  2. Compile & email — sends the complete HTML book as an attachment to hello@24stories.co.za and sets BookCompiledDate in Airtable. Open the attachment in Chrome to export the print-ready PDF.

After compiling

  1. Open the attached HTML file in Chrome
  2. Review every chapter — content, images, titles, order
  3. If anything needs fixing: edit in Airtable → recompile here
  4. File → Print → Save as PDF
    Paper: A5  |  Margins: None  |  Background graphics: On
  5. Send PDF to printer
  6. Return to Airtable → tick BookDispatchEmailSent
