1. Project Overview

24 Stories is a once-off subscription service (R6,795 upfront) that guides a storyteller through 26 weekly story prompts, edits each story professionally, delivers each story to family by email, and produces a printed hardcover Legacy Book.

Platform for this task — TBD. Make is not currently available. Three options to discuss with client before starting:

Option A — Zapier (recommended if staying no-code): Netlify has a native Zapier integration. Zap: Netlify form submission → Airtable create record. Simple, reliable, no code. Free tier likely sufficient for this volume.

Option B — Netlify function (no third-party platform): Convert each form to submit via a small JavaScript fetch call to a Netlify serverless function. The function posts directly to Airtable's API. Recommendation: Option B (Netlify function) if the developer is comfortable with a small amount of code — it is self-contained, costs nothing extra, and keeps the architecture clean. Option A (Zapier) if a no-code approach is preferred.
