How to save as a Gmail Template:

1. Enable templates if not already on: Gmail → Settings (gear icon) → See all settings → Advanced → Enable Templates → Save Changes

2. Open a new Compose window. Paste the subject line. Paste the body below.

3. Click the three-dot menu (More options, bottom right of compose) → Templates → Save draft as template → Save as new template

4. Name it exactly as labelled below → OK

5. To use: when composing a reply, click the three-dot menu → Templates → select the template. Replace [Name] with the person's first name before sending.

Signature: set the default signature for hello@24stories.co.za to Team in Gmail Settings.
⚠ Before saving each template: delete the signature from the bottom of the compose window. If you don't, Gmail will append the signature twice — once from the template and once automatically.
