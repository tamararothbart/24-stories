How to use this page. For each email: (1) click the Subject field → Cmd+A → Cmd+C → paste into Mailjet subject field. (2) Click the HTML field → Cmd+A → Cmd+C → paste into Mailjet HTML content field. Or use the Copy buttons.

Make variable syntax: {{StorytellerFirstName}} — Make substitutes these before sending to Mailjet. When building in Make, the exact prefix (e.g. 3.) depends on which module the data comes from. Map using Make's field-picker where possible; type the variable name if you know the field.

Library URL: construct in Make as https://24stories.co.za/library.html?id={{LibraryToken}}
tell.html link: construct in Make as https://24stories.co.za/tell.html?id={{LibraryToken}}&week={{Prompts.Week}}&weekname={{replace(WeekName;" ";"+")}}&theme={{replace(Theme;" ";"+")}}&prompt={{replace(PromptText;" ";"+")}}&angles={{replace(OtherAngles;" ";"+")}}
Important — week parameter: use {{Prompts.Week}} (the Week field from the Prompts record lookup), NOT {{PromptNumber}} from the Subscriber. At email send time in Scenarios 3 and 4, PromptNumber has not yet been incremented — using it would pass the previous week number. The Prompts record already contains the correct week.
