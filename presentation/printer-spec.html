What we produce
The 24 Stories Legacy Book

Each subscriber to 24 Stories spends 26 weeks recording their life stories — one prompt per week. Every story is edited professionally and delivered to their family by email. At the end of the journey, all 26 chapters are compiled into a printed hardcover book: a legacy edition, designed to last generations.

The book is typeset automatically from the subscriber's stories, photographs, and book details. It is exported from Chrome as a print-ready PDF. Our specification is fixed. Every order uses the same format.

Mirror margins are set in the PDF via CSS. Do not add or alter margins in pre-press software. The PDF is authoritative.

On the first printed proof, please verify that alternating spine margins are honoured — recto pages should have 20mm at the spine (left edge), verso pages 15mm at the spine (right edge).

Content
Book Structure — Page Order

The page order is fixed and generated automatically. Every book follows this sequence.

  1. Title Page Full-bleed. Background: subscriber's cloth colour (black #1A1A1A / blue #1C2B3F / red #3A0E0E). Book title in Bebas Neue, upper left. Author name block lower right: name in Bebas Neue, "A Collection of Stories" in small caps below. No image.
  2. Portrait Photograph Full-bleed, no caption. Included only if subscriber has uploaded a portrait. Orientation: portrait preferred. No border or frame.
  3. Dedication Page Full-bleed. Centred. Georgia italic. Subscriber's written dedication. Included only if dedication text is provided.
  4. Epigraph Page Full-bleed. Centred. Georgia italic. Subscriber's chosen quote or epigraph. Included only if epigraph text is provided.
  5. Table of Contents Bebas Neue "Contents" heading. Chapter numbers in gold (#B8976A), chapter titles in Georgia. No dates — dates do not appear anywhere in the book.
  6. Chapters × 26 (or fewer if subscriber has not completed all prompts) Each chapter = one chapter-page followed (if an image was supplied) by one photo-page.
    Chapter page: Bebas Neue chapter title, Georgia body text, justified, mirror margins.
    Photo page: Always on its own full-bleed page, always after the chapter text — never inline within text. Caption in Georgia italic below image.
    Chapter order is set by the subscriber in their Story Library (ChapterOrder field). No dates in chapter headings or text.
  7. Colophon Full-bleed. Bottom-centred. Georgia. "This book was made for [Subscriber Name]. Produced by 24 Stories."
File
PDF Specification
File
Format
PDF — generated in Chrome via File → Print → Save as PDF
Paper size
170 × 240mm — enter as custom paper size in Chrome print dialog (170mm width × 240mm height). Margins: None (CSS handles all margins). Background graphics: On.
Fonts
Embedded in PDF. Bebas Neue (display) + Georgia (body). No substitution required. Note: Bebas Neue requires internet access at export time — once exported, fonts are embedded and the printer needs no internet connection.
Colour space
RGB (Chrome output). Text is black throughout. Images are colour RGB.
Images
Cloudinary full-resolution output, minimum 1,000px on shortest edge, embedded in PDF
Spec sheet
The PDF begins with a printer spec reference panel marked ".no-print" — this does not appear in the exported PDF. Only book content is in the PDF.
How to export 1. Open the HTML attachment from the BOOK COMPILED email in Chrome (not Safari, not Mail preview).
2. Review the complete book — content, images, chapter order, chapter titles.
3. File → Print → Save as PDF. Paper size: custom 170 × 240mm (enter manually). Margins: None. Background graphics: On.
4. Save PDF. Attach to print order email.

What to verify on the proof
Mirror margins
Recto pages: spine margin (left) = 20mm. Verso pages: spine margin (right) = 15mm. Verify these alternate correctly — this is a CSS-set feature that may or may not survive PDF pre-press.
Full-bleed pages
Title page, portrait, chapter photos, dedication, epigraph, colophon — content to trim edge, no margin showing.
Photo pages
Each chapter photo appears on its own page after the chapter text. Never inline within text.
Image resolution
Flag any image below 150dpi at trim size before pressing.
Cover cloth
Verify cloth colour matches the order (Black / Blue / Red). Confirm debossed lettering not foil.
Delivery
Courier
Tracked courier to the delivery address specified in the print order. Advise estimated dispatch date and tracking number once handed to courier.
Delays
If any delay occurs beyond your quoted turnaround, notify hello@24stories.co.za before the due date passes.

We advise subscribers to allow up to 4 weeks from order to delivery. Please confirm your standard turnaround at time of quoting.
