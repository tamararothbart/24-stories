24 Stories — Social Media Visuals

Seven Facebook post visuals, ready to screenshot. Each panel is exactly 1080×1080px.

How to save each visual as an image (Chrome on Mac):

  1. Make sure you are online (fonts load from Google)
  2. Open Chrome. Press Cmd + 0 to set zoom to 100%
  3. Right-click anywhere on a panel → Inspect
  4. In the Elements panel on the right, the highlighted line will be the panel div
  5. Right-click that highlighted line → Capture node screenshot
  6. The image downloads automatically to your Downloads folder — exactly 1080×1080px

Repeat for each of the 7 panels. Takes about 2 minutes per panel once you know the steps.
